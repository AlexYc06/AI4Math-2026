## 阶段二：形式化审计

选题为「三维 Euler 与 Navier–Stokes 有限时间爆破的证明可读化」，阅读一手材料后转向**信任链审计**：核查两份 Lean 4 形式化各自覆盖了什么。

索引：[`ns_euler_readability/00_研究计划.md`](ns_euler_readability/00_研究计划.md)

### 方法

把从原始问题到数值证据的过程分成五个环节（原始问题、论文定理、Lean 命题、Lean 证明、证书数据），每个环节标一个等级：

- **M** 机器验证（内核与独立内核均通过）
- **C** 计算验证（区间算术可复现）
- **R** 需人阅读两份文本作比较
- **N** 缺少材料

据此把待核断言编号为 $G_1$ 至 $G_9$。

### 两条主要发现

**一、压力梯度的衰减条件。** 形式化要求自相似剖面的压力梯度满足 $|\nabla q|\le C(1+|y|)^{-3}$。论文只要求速度场满足 $|W|\le C_W(1+|y|)^{-1}$，其 Remark 1.2 明确指出所用内部估计**不需要压力界**。按剖面方程解出 $\nabla q$ 后逐项估计，$\tfrac12W$ 与 $\tfrac12(y\cdot\nabla)W$ 两项均为 $(1+|y|)^{-1}$ 量级且同为主项，不会相互抵消，故只能得到 $(1+|y|)^{-1}$。形式化的假设严格强于论文，相应定理严格弱于论文。详见 [`18_W11_G3与G4判定.md`](ns_euler_readability/18_W11_G3与G4判定.md)。

**二、两份不同的证明。** Euler 论文的 Corollary 8.3 引用周期情形的 Beale–Kato–Majda 判据完成证明；Lean 版本不使用该判据，改用涡量下界在相邻激活时刻之间积分，并为此证明了一条时间区间下界的估计。两者结论相同、路径不同。详见 [`09_G7判定与G9闭合.md`](ns_euler_readability/09_G7判定与G9闭合.md)。

### 一处容易误解之处

Lean 仓库说明提到「从弱剖面到光滑剖面这一步不在任何 statement 文件中」。库中存在内容正是这一步的定理，它只是没有被提升为 statement。**形式化验证的边界在接口，不在证明。**

### 命题比对

Euler 的形式化含 42 个节点，对其中 11 个做了逐子句比对，未发现语义差异。详见 [`17_G6总体判定.md`](ns_euler_readability/17_G6总体判定.md)。
