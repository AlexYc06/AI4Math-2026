## 抽样 02：`proposition_8_2`

### 2.1 两边原文

**论文（L2507）**，一句话：

> **Proposition 8.2.** The solution has bounded velocity on $[0,T_\infty)$, and $|\operatorname{curl}u(t,0)|\longrightarrow\infty$ as $t\uparrow T_\infty$.

**Lean（L185–189）**

```lean
def Statement.proposition_8_2 : Prop :=
  ∀ (P) (c : InductiveEulerConstruction P) (C T : ℝ) (u : Velocity) (p : Pressure),
    Theorem71Conclusions c C T → Proposition81Conclusions c T u p →
      Proposition82Conclusions c T u
```

而 `Proposition82Conclusions`（`S678_Vocabulary.lean` L276–283）有**三个**字段：

| 字段 | 内容 | 论文里有吗 |
|---|---|---|
| `bounded_velocity` | $\exists M,\ \forall t\in[0,T),\ \|u(t)\|_\infty\le M$ | ✅ |
| `central_curl` | $\|\operatorname{curl}u(t,0)\|\to\infty$ | ✅ |
| **`curl_lower`** | $\exists c_1>0,C_1,\ \forall^\infty j,\ \forall t\in[t_j,t_{j+1})$：$c_1\lambda_{j-1}^{1/8}-C_1\lambda_{j-1}^{1/32}-C_1\le\|\operatorname{curl}u(t,0)\|$ | ❌ **结论里没有**（但在**证明**里有，即 (8.1) 之后的推导） |

### 2.2 判定

- **差异类型 (c)：结论加强。**
- **是否忠实？** 是。论文把该下界写在**证明内部**（L2520 的 (8.1) 之后的估计），没有提升为定理结论；Lean 把它导出成字段。docstring 明说："Exports (ledger): the curl lower bound (8.2) of the proof, passed to the limit `u` … which Corollary 8.3 uses in place of the Beale–Kato–Majda criterion."
- **风险：0。** 结论加强不会使定理变弱；唯一需要注意的是：**用这个结论的人（8.3）必须知道它来自"证明内部"，因此依赖 8.2 的证明细节而非仅其陈述**——这正是 `09` 里 G7 分析的起点。

> **一个表述上的小瑕疵**：`p` 是量化变量但不出现在结论 `Proposition82Conclusions c T u` 里。无害（多余的量化），但说明这两个命题是"按论文的设定"而非"按最小假设"写的。

### 3.3 唯一的真差异：T3 的求和指标

- 论文：$\displaystyle\sum_{i=1}^{j-1}\lambda_{i-1}^{-1}$
- Lean：$\displaystyle\sum_{i\in\mathrm{range}(j)}\lambda_i^{-1}=\sum_{i=0}^{j-1}\lambda_i^{-1}$

Lean 的求和**多了一项** $\lambda_0^{-1}=N^{-1}$，因此 Lean 的界**略宽**（结论略弱）。差异量级 $N^{-1}$，而 $N$ 是任意大的初始频率，故：

- 若下游（强制性 $H^\#\le\mathrm{Id}$）的预算有正裕量，则无害；
- 若预算紧到 $N^{-1}$ 级别，则会出问题。

**判定 (c)：结论略弱，量级 $N^{-1}$，需在下游核实裕量。** 记为 **Q6**。

> 这是三个样本里第一处**非无害**的性质差异。它不大，但值得记：因为 §7 的求和"预算"正是 $\sum\lambda_i^{-1}$，多一项就是多一份压力。

### 3.4 一个真正的可读性收益：$C$ 被钉死

论文在三处出现"绝对常数 $C$"：

- (2.23)：$C^{-1}(\varepsilon\varepsilon_+)^{-1/2}\le\sigma_+/(\lambda\max|a|)\le C(\varepsilon\varepsilon_+)^{-1/2}$；
- (7.3)：$C^{-1}\lambda_j^{1/4}\le\sigma_j\le C\lambda_j^{1/4}L_{j+1}^2$；
- Theorem 7.1 的正文："with an absolute constant $C\ge2$ for which (2.23) holds"。

**Lean 把三处统一到 $C=18e^3$**：`proposition_2_8` 用它作上下界（下界用 $e^{-1}/4$，见 `12`），`theorem_7_1` 里 `P.strengthConstant = 18 * Real.exp 3`，`Theorem71Conclusions` 里 `2 ≤ C`。

> **这是"形式化比论文更可读"的第二个例证。** 论文读者要自己相信"同一个 $C$ 能同时满足 (2.23) 的两侧与 (7.3)"；Lean 读者直接看到 $18e^3$ 被贯穿使用。而且这也回答了 §1.5 参数阶梯里"$C$ 到底多大"的问题。
