## 三、四个结构发现

### F1｜两处 frontier 为空，但都不是隐瞒

- `corollary_8_3`：Lean 的 Cites 为 **none**，而论文中它依赖 Prop 8.2。README 已说明：Lean 直接用了 8.2 证明内部的涡量下界，因为 BKM 判据没形式化。
- `remark_1_2`：Cites 为 none，由库定理 `auxiliaryTerminalSmoothness` 证明，ledger 决策 **D28** 明确豁免。

两处都是**文档化的例外**。但因为都在主链上，报告中必须显式处理。

### F2｜G7 升级为高优先级

主链是

```
theorem_7_1 → section8_setting ┐
proposition_8_1 ───────────────┤
proposition_8_2 ───────────────┼→ theorem_1_1
corollary_8_3（frontier 空）───┤
proposition_8_4 ───────────────┘
```

**`corollary_8_3` 在 Theorem 1.1 的依赖闭包内。** 所以"用 Prop 8.2 绕开 BKM"不是旁支补丁，而是主定理必经之路。这修正了 W01 的优先级估计。

### F3｜新缺口 G9：「导出假设」的接口完整性

`proposition_8_2` 不引用 `7.1` 或 `8.1`，它是个条件性命题，其假设里包含 Theorem 7.1 的**输出**（ledger D11 提到的 `Theorem71Conclusions` 的 `comparison`、`window_upper` 字段）。

于是有一条新检查项：**这些导出字段是否恰好覆盖 Prop 8.2 所需？** 多给无妨，少给则链断。记为 **G9**。

### F4｜D22 是"论文引用 ≠ 数学依赖"的活样本

> D22：`κ·a=0` 沿 (2.1) 的保持对**任意背景 B** 都成立，论文正文在 Lemma 2.1 假设**失败**处用了它（`04_localized_wave.tex:58-59`，`08b_induction.tex:296`）。

所以 `theorem_7_1` 的 Cites 里没有 `lemma_2_1`。这说明 spine 的规则（frontier = TeX 引用集合）本身会把一些节点降为 glue、一些 glue 升为节点，共约 29 条人工判断。**这些判断就是 G6 的可审内容。**

## 四、一个对 G5 有利的结构性论据

`ExtendedCertificateChallenge.lean` 里有两条定理：

```
isExtendedCertificate_withUnitWeight
isExtendedCertificate_atProfile
```

后者说明：**任一剖面都给出一个证书**。因此形式化的证书定义**不弱于**"存在剖面"——如果 13 处差异中有"漏条件"，`atProfile` 的证明会失败。

这削弱了"形式化定义过弱"的风险，但**不排除"形式化定义过强"**：若形式化要求比论文多，则附录 C 的数据未必满足它，反而使 G1 更难。**方向判断要在 W7 读论文 §7.1–7.3 后才能做。**
