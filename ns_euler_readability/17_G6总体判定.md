## 抽样 10：`theorem_A_1`（App A 的核心）

### 10.1 两边

**论文（L2586–2600）**

> Assume, for some $\kappa,\mu>0$,
> $$\text{(A.1)}\quad K\ge\kappa I,\qquad \text{(A.2)}\quad \int_I Kz_t\cdot z_t+\Omega z_t\cdot z\,dt\ge\mu\int_I\lvert z_t\rvert^2dt .$$
> Put
> $$Q=2+\kappa^{-1}+\mu^{-1}+\|K\|_1+\|\Omega\|_1 .$$
> **Theorem A.1.** Under (A.1)–(A.2), let $L\in C(I;C^{0,1/2})$. There are unique $z\in C^1$, $c$, $\nabla\varphi$ satisfying … They obey
> $$\tag{A.3}\|z_t\|_0\le CQ^p\|L\|_0 .$$
> If $K,\Omega,L$ are smooth on $I\times\mathbb T^3$, then so are $z,c,\nabla\varphi$.

**Lean（L195–215，摘要）**

```lean
∃ C p, 0 ≤ C ∧
∀ K Ω, ∀ κ μ K₀ K₁ Ω₀ Ω₁,
  (∀ t a, IsSelfAdjoint (K t a)) → (∀ t a, (Ω t a).adjoint = -(Ω t a)) →
  EndpointCoefficientC1Bound K K₀ K₁ → EndpointCoefficientC1Bound Ω Ω₀ Ω₁ →
  0 < κ → (∀ t a w, κ * ‖w‖^2 ≤ ⟪K t a w, w⟫) →
  0 < μ → EndpointSobolevEnergyBound K Ω μ →
  let Q := 2 + κ⁻¹ + μ⁻¹ + K₀ + K₁ + Ω₀ + Ω₁
  ∀ L, ContinuousOn L J(1) → ∃ z v c φ G, (解 ∧ 唯一 ∧ ‖v‖ ≤ C*Q^p*‖L‖ ∧ (光滑性))
```

### 10.2 判定

- **$Q$ 的形式与论文逐字相同**：$2+\kappa^{-1}+\mu^{-1}+K_0+K_1+\Omega_0+\Omega_1$，只是把 $\|K\|_1$ 拆成「值界 $K_0$ + 一阶导界 $K_1$」。
  - Lean 的 docstring 自己承认这是**双向调整**："this **weakens the hypothesis** and **strengthens the bound**"。
- **(A.1)(A.2)** 逐字对应；额外要求 $K$ 自伴、$\Omega$ 反自伴（论文在 (A.1)–(A.2) 的语境里默认，Lean 显式）。
- **(A.3)** 逐字：`‖v‖ ≤ C * Q^p * ‖L‖`。
- **光滑性条款**：论文"If $K,\Omega,L$ smooth then so are $z,c,\nabla\varphi$"；Lean 的对应子句完整。
- $C,p$ 在**最外层**被 $\exists$，故绝对。✓

**判定**：忠实。**$Q$ 是本课题发现的第五个、也是最结构化的"被显式化的常数"**——它把 App A 里那个抽象的"quantity $Q$"变成了一个可以逐项检查的和。

## 14. 一个可以写进终稿的结论

11 个样本给出一个**稳定的模式**：

$$\text{形式化的差异 }=\text{ 常数显式化 }+\text{ 量化次序显式化 }+\text{ 极少量表示层偏移}$$

而**没有**出现"形式化证明了一个更弱的定理"或"证明了一个不同的定理"。

这支持一个对 AI 形式化的正面判断：

> **在"命题层"上，这份形式化是忠实的。** 它的价值主要不是"验证了论文"，而是**把论文里所有"存在某个常数/某个函数"的地方变成了可以逐项检查的对象**——包括 5 个被显式化的常数（$18e^3$、$C_{\text{step}}=\Gamma D^b$、$C_n$、$Q$、以及 (4.10) 的 $A$）。
