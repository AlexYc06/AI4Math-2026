## 三、抽样 09：散文约束 → 结构约束

论文用一句英文表达"误差矩阵不依赖振幅向量"：

> "$E$ is the same for all amplitude vectors"

Lean 用**量化次序**表达：`∃ ℰ` 出现在 `∀ a` **之前**。

> 这是形式化把**散文约束变成结构约束**的典型手法——而且比散文更不容易被误读。读者不会怀疑"same"是"存在某个依赖于 a 的 E"还是"同一个 E"；`∃` 在 `∀` 之前，没有歧义。

## 四、抽样 10：$Q$ 逐字对应

论文 App A：

$$Q=2+\kappa^{-1}+\mu^{-1}+\|K\|_1+\|\Omega\|_1,\qquad \|z_t\|_0\le CQ^p\|L\|_0$$

Lean：`let Q := 2 + κ⁻¹ + μ⁻¹ + K₀ + K₁ + Ω₀ + Ω₁`，其余逐字。

只把 $\|K\|_1$ 拆成「值界 $K_0$ + 一阶导界 $K_1$」。Lean 的 docstring 自己承认这是**双向调整**："this **weakens the hypothesis** and **strengthens the bound**"——这是 11 个样本里唯一一处形式化自己标注为"双向"的。

**$Q$ 是本课题发现的第五个、也是最结构化地被显式化的常数。**

## 五、抽样 11：顶层定理与 D1 的镜像

`theorem_1_1` 与论文 Theorem 1.1 逐条对应，并额外显式化了"极大性"：

```lean
∀ (T' : ℝ) (v : Velocity) (q : Pressure), IsMaximalEulerSolution T' v q → v 0 = u₀ → T' = T ∧ EqOn v u (Ico 0 T)
```

把论文措辞 "whose **maximal** classical solution" 变成显式合取项。

> **这恰好是 D1 的镜像**：在顶层，Lean 把"极大性"说足了；在 Cor 8.3，它把"有限性"说漏了。
> 同一个形式化系统，在"重要"的地方多说，在"次要"的地方少说。**这不像错误，更像注意力分配。**

## 七、一个可以写进终稿的判断

$$\text{差异}=\text{常数显式化}+\text{量化次序显式化}+\text{极少量表示层偏移}$$
