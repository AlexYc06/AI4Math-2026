## 抽样 05：`proposition_5_2`（均方程的"损失一阶导数"估计）

### 5.1 两边原文

**论文（L1519–1521）**

> **Proposition 5.2.** There is an absolute exponent $C$ such that, for every $n\ge0$, every solution of the mean equation (5.11) satisfies
> $$\tag{5.12}\|B\| \le C_n D^C\|f\|_{[n]}\ \text{的}\ [n+1]\ \text{范数版本}.$$

（原文经 `pdftotext` 后上下标错位；Lean 的 docstring 复原为 $\|B\|_{[n]}\le C_n\mathsf D^C\|\bar f\|_{[n+1]}$，与论文 §5.3 正文"Passing to the supremum norms by (D.2) **costs one derivative of the source**"一致。）

**Lean（L112–120）**

```lean
def Statement.proposition_5_2 : Prop :=
  ∃ a₀ : ℕ, ∀ a : ℕ, a₀ ≤ a → ∃ C : ℕ, ∃ K : ℕ → ℝ,
    ∀ {T} (hT : 0 < T) {U X pU k D lam} (d : ParentGeometry hT U X k),
      S5.Parent T U X pU D lam →
      ∀ (f B : HierarchyTwistedProfile T k Vec3) (q : … ℝ),
        S5.MeanSolution d f B q →
        ∀ n : ℕ,
          S5.uNorm (S5.radius D a) (S5.width lam) n B ≤
            K n * D ^ C * S5.uNorm (S5.radius D a) (S5.width lam) (n + 1) f
```

### 5.2 逐条对照

| # | 论文 | Lean | 判定 |
|---|---|---|---|
| 1 | "absolute exponent $C$" | `∃ C : ℕ` 位于 `∀ T U X pU k D lam` **之前**，故与父流、$D$、$\lambda$ 全无关 | ✅ **"绝对"被量化次序严格保证** |
| 2 | $C_n$ | `K : ℕ → ℝ`，同样位于父流之前 | ✅ |
| 3 | "for every $n\ge0$" | `∀ n : ℕ` | ✅ |
| 4 | "every solution of (5.11)" | `S5.MeanSolution d f B q` | ✅ |
| 5 | $\|B\|_{[n]}\le C_nD^C\|\bar f\|_{[n+1]}$ | 逐字 | ✅ |
| 6 | $\ell_*=\mathsf D^{-a}$，"a sufficiently large negative power of $D$"（L1525） | `∃ a₀, ∀ a ≥ a₀`，范数用 `S5.radius D a` | ✅ **显式化**：论文只说"充分大的负幂"，Lean 给出阈值 $a_0$ |
| 7 | —— | `K` 在 `a` 之后选取，故 $C_n$ **可以依赖** $a$ | ⚠️ **见 §5.3** |

### 5.3 唯一的差异：$C_n$ 是否可以依赖 $\ell_*$

量化次序是

$$\exists a_0,\ \forall a\ge a_0,\ \exists C,\ \exists K,\ \forall(\text{父流}),\dots$$

所以 $C$ 与 $K$ 可以依赖 $a$（即依赖 $\ell_*=\mathsf D^{-a}$），但不依赖父流。

论文写 "an absolute exponent $C$"，且 $C_n$ 通常理解为只依赖 $n$ 与固定剖面。**若 $\ell_*$ 是可自由选取的参数，则 Lean 的常数依赖它是一个（极小的）削弱。**

影响评估：
- $\ell_*$ 在 §1.5 的参数阶梯里被固定（$\ell_*=D^{-a}$ 取定一个 $a$），所以实际使用中不会"对所有 $a$ 一致"。
- 因此这处削弱**实践中无害**，但**陈述上**应当知道。

**判定**：(c) 结论略弱，记为 **D2**。

### 5.4 一个可读性收益

论文的 (5.12) 里 $[n]$ 与 $[n+1]$ 的下标差，是"损失一阶导数"的全部信息量。**Lean 把它写成 `n` 与 `(n + 1)` 两个显式参数**，读者一眼看到那一阶从哪来。这比论文的排版（下标在 PDF 里还会掉行）清楚得多。

## 抽样 06：`lemma_5_10`（流形变的界）

### 6.1 两边原文

**论文（L2055 区）**，docstring 转述为：

> Let $v$ be a smooth divergence-free field on $[0,T]\times\mathbb T^3$ with $\|v\|_{C_tC^2}\le\lambda^{-5/2}$. The flow $Y$ of $V+v$ from time zero satisfies (5.53) $\sup\lvert(D_aY)^{\pm1}\rvert\le C_{\text{step}}\lambda^{1/4}$.

**Lean（L535–555，摘要）**

```lean
∃ a₀, ∀ a ≥ a₀, ∃ b₀, ∃ Γ₀, ∀ b ≥ b₀, ∀ Γ, (∀ P, Γ₀ P ≤ Γ P) →
  ∀ … (d : ParentGeometry) (χ : PaperWaveCutoff t₀ T),
    S5.Parent … → S5.Launch … → S5.Origin … → S5.IsSeed … → ∀ P ≥ 2,
    ∀ (R S u), S5.IsExpansion d pU χ (radius D a) (width lam) amp P R S u →
    Γ P * D ^ b * lam ^ (-1/12) ≤ 1 →
    let V := U + graphRead … (S5.expansion u P)
    let Cflow := Γ P * D ^ b * lam ^ (1/4)
    ∀ v, ContDiffOn … → SpatiallyPeriodic … → divergence = 0 →
      (∀ t, ∀ j ≤ 2, ∀ x, ‖iteratedFDeriv ℝ j (v t) x‖ ≤ lam ^ (-5/2)) →
      (∃ Yf, DeformationOn (V + v) Yf T Cflow) ∧
      ∀ Yf, IsLabelFlowOn (V + v) Yf (Icc 0 T) →
        ∀ t, ∀ x, ‖fderiv (Yf 0 t) x‖ ≤ Cflow ∧ ‖fderiv (Yf t 0) x‖ ≤ Cflow
```

### 6.2 逐条对照

| # | 论文 | Lean | 判定 |
|---|---|---|---|
| 1 | $v$ 光滑、无散、周期 | `ContDiffOn ℝ ∞`、`divergence = 0`、`SpatiallyPeriodic` | ✅ |
| 2 | $\|v\|_{C_tC^2}\le\lambda^{-5/2}$ | `∀ j ≤ 2, ∀ x, ‖iteratedFDeriv ℝ j (v t) x‖ ≤ λ^{-5/2}` | ⚠️ **更强**（逐阶各自 $\le$，而非范数 $\le$） |
| 3 | $\sup\lvert(D_aY)^{\pm1}\rvert\le C_{\text{step}}\lambda^{1/4}$ | `‖fderiv (Yf 0 t) x‖ ≤ Cflow`（正向）与 `‖fderiv (Yf t 0) x‖ ≤ Cflow`（逆向） | ✅ 正逆两支都断言 |
| 4 | $C_{\text{step}}$（未给形式） | `Cflow := Γ P * D ^ b * lam ^ (1/4)` | ✅ **显式化**：$C_{\text{step}}=\Gamma(P)D^b$ |
| 5 | 流 $Y$ 的存在性（默认） | `∃ Yf, DeformationOn (V+v) Yf T Cflow` | ✅ **补上存在性** |
| 6 | —— | `Γ P * D^b * λ^{-1/12} ≤ 1` 作为假设 | ✅ 小性条件显式化 |
| 7 | 深度 $P$ | `∀ P ≥ 2` | ✅ |

### 6.3 判定

- **差异类型**：(b) 假设加强（第 2 条，逐阶界 vs 范数界）+ (c) 结论加强（$C_{\text{step}}$ 显式、补存在性）。
- **风险**：低。逐阶界的加强量为常数因子（$C^2$ 范数 $\le 3\max_j$），而 $\lambda^{-5/2}$ 中的 $\lambda$ 很大，实际使用中余量充足。
- **但要注意**：若下游把 $\lambda^{-5/2}$ 与别的量做乘法并凑到临界，常数因子 3 可能致命。**标注为需在下游核**（与 Q6 同类）。

### 6.4 与台账 D9/D10 的关系

台账 D9 说"Lemma 5.10 引用 Proposition 5.4"，D10 说"5.10 证明中的乘积界是逐点 Leibniz glue"。

**这两条在陈述层看不到**——Lean 的 `lemma_5_10` 陈述里既无 `proposition_5_4`，也无乘积界；引用发生在**证明内部**（通过 `S5.IsExpansion` 的展开式与 §5.6 的剖面）。

> 这提示一个审计方法上的要点：**spine 的 `cites` 只由证明依赖决定，不从陈述抽取。** 因此"读陈述"能核 (b)(c)(d) 类差异，**核不了 `cites` 本身**。后者只能靠读证明或读台账。
