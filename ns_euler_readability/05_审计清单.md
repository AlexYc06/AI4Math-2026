# 审计清单：信任链（Trust-Chain Ledger）

> **本文件是本课题的核心产出。** 它逐条记录：从"Euler/NS 方程"到"爆破定理"之间，信任依赖了哪些非机器环节，每一环当前处于什么状态，以及把它升级到上一级需要做什么。
>
> 版本：v0.1（W1）｜最后更新：2026-11-22
> 配套：`02_证明路线图.md`（缺口在架构中的位置）、`03_技术笔记_Euler.md`、`04_技术笔记_NS.md`

## 0. 使用方法

1. 每一行是一个**可独立判定的断言**，不是"某篇论文"。
2. 判定等级只有四档（§1），不允许写"应该是""看起来"。
3. 每行必须有**证据定位**（原文引用 + 文件行号）或标注"**未找到证据**"。
4. "升级所需"一列写**具体动作**（跑什么命令、读哪一节、核哪个不等式），不写"进一步研究"。
5. 审计者可以填"**未判定**"，但必须写清卡在哪。

## 5. 待核疑点（Pending Issues）

### P1｜$|\nabla q|\le C(1+|y|)^{-3}$ 的理由不充分（对应 G4）

论文的剖面方程（1.2a）：

$$\partial_sW+\tfrac12W+\tfrac12(y\cdot\nabla)W-\Delta W+(W\cdot\nabla)W+\nabla q=0.$$

解出压力梯度：

$$\nabla q=-\partial_sW-\tfrac12W-\tfrac12(y\cdot\nabla)W+\Delta W-(W\cdot\nabla)W.$$

用论文 (1.3) 的界 $|W|\le C(1+|y|)^{-1}$、$|\nabla W|\le C(1+|y|)^{-2}$ 逐项估计：

| 项 | 界 |
|---|---|
| $\partial_sW$ | 无先验界（需要额外假设 $W$ 在 $s$ 方向一致正则） |
| $\tfrac12W$ | $O((1+|y|)^{-1})$ |
| $\tfrac12(y\cdot\nabla)W$ | $O\bigl(|y|(1+|y|)^{-2}\bigr)=O((1+|y|)^{-1})$ |
| $\Delta W$ | $O((1+|y|)^{-3})$（若 $|\nabla^2W|$ 有此界） |
| $(W\cdot\nabla)W$ | $O((1+|y|)^{-3})$ |

**结论**：逐项估计只给 $|\nabla q|=O((1+|y|)^{-1})$，**不是** $(1+|y|)^{-3}$。README 的一行理由（"since the equation determines the pressure gradient"）按字面不成立。

**可能的正确论证**（待核）：改用压力方程的整体形式。由 $\operatorname{div}$ 取散度，
$$-\Delta q=\partial_i\partial_j(W_iW_j),$$
右端是 $|y|^{-2}$ 量级的源（在 $W\sim|y|^{-1}$ 时），其在 $\mathbb R^3$ 上的 Newton 势衰减为 $|y|^{-2}$ 量级（若源的积分在无穷远有合适意义），于是 $\nabla q=O(|y|^{-3})$。**但这需要 $W$ 的远场有更强的结构（例如角向平均为零），不能只由 (1.3) 得到。**

**三个可能的结局**：
1. 论文/README 有更细的论证未写出 → 我在报告中补出，G4 保持"已解决"；
2. 形式化假设确实严格更强 → 需要证明"存在满足更强假设的剖面"，而这**不在**论文中；
3. 存在反例（构造一个满足 (1.3) 但 $\nabla q$ 衰减更慢的剖面）→ 这是**真缺口**。

**当前判定**：未定。这是 W10 的核心任务。
